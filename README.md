# Python Mini Projects & Games

This repository is a collection of beginner to intermediate-level Python projects built as part of my learning journey in software engineering. 
The focus is on applying Object-Oriented Programming (OOP) concepts, developing simple GUI applications using Tkinter, and creating logic-based games and simulations.

## Projects Included

- **Snake Game**  
  A classic 2D arcade-style game where the snake grows with each food item eaten. Built using Tkinter and keyboard event handling.

- **Pong Game**  
  A two-player paddle game developed with Python’s GUI module and basic collision detection logic.

- **Turtle Race**  
  A race simulation using Python’s turtle graphics module for a fun and visual representation of random movement.

- **Car Dodge Game**  
  A small game where the player avoids incoming cars. A great project for practicing object movement and game loops.

- **Coffee Machine (OOP Project)** 
  A command-line simulation of a coffee vending machine. Demonstrates use of classes, inventory tracking, and basic user input handling.

- **C++ Projects**  
  Includes a calculator and a two-player Tic-Tac-Toe game, both built using C++ with OOP principles.
## Technologies Used
- Python 3  
- Tkinter (GUI)  
- C++  
- Object-Oriented Programming (OOP)  
- Turtle Module  
- Basic File I/O  
- CLI (Command Line Interface)
